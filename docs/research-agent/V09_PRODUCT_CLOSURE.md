D-077 chooses the existing user journey (D) over new discovery/provider breadth.
Today coverage remains limited; independent varied-headline clustering and
materiality recall did not justify more tuning. Existing financial and research
engines can already answer a useful bounded task when their inputs reach it.

The fictional oracle in `evals/closure_journey.py` starts with an explicitly
confirmed fixture thesis requiring customer retention and contract cash
qualification. Six original acceptance-news receipts lead to Fast provisional
HOLD, awaiting cash qualification. Same-task Deep adds exact four-quarter SEC
fixtures and one formal cash-condition receipt; the scripted oracle changes to
provisional ADD with the original demand counterevidence intact. The no-gain
control stays HOLD/UNRESOLVED. This is test orchestration, not evidence that a
real model chooses better actions or that real investments should follow it.

`tests/test_closure_journey.py` executes the production HTTP/task/SQLite path.
The existing Console now offers an explicit next-round mode selector, so a user
can continue Fast as Deep in the same task. The fee dialog discloses that choice;
cancellation does not submit. Historical/public-replay controls remain read-only.
Both revisions retain all six original IDs and the confirmed thesis in actual
model context; prior revision bytes remain unchanged. Fast keeps 12KB/eight
sources; Deep keeps 24KB/eighteen. Exact duplicate news excerpts/titles can
reference a selected original's text. Every source still has its own identity,
URL, times, hash and distinct metadata. Duplicate identity/times in news
`market_identity` refer to the enclosing evidence; derived freshness/session
fields remain. This is prompt projection, never historical evidence mutation or
proof of event equivalence. Other inputs can still exceed the finite budget;
the omitted-source manifest remains authoritative, not a full-coverage claim.

The dated-valuation form accepts an optional second user-defined price. Python
Decimal computes the same-date, same-shares, same-TTM difference, with exact
receipt values and explicitly approximate display values for ratios. At 100
shares, prices 12.50 and 10 imply 1,250 versus 1,000 USD, a -250 USD equity-value
difference and -20% input-price sensitivity. Neither price is a verified quote,
market move, return or target. No Provider display-only data is reused. Original
Action, thesis, portfolio, history and Deep context remain unchanged. The form
links the price calculation back to saved thesis delta, counterevidence and
change conditions rather than manufacturing a new investment judgment.

Legacy missing listing identity cannot be upgraded by user checkboxes. A
hash-bound single-ticker SEC identity must be known before a date-only observed
price day; unknown/later identity downgrades to ILLUSTRATIVE_SCENARIO. A ticker map
still does not establish economic class equivalence. Shares 101–120 days old
can support only an explicit old-share scenario; the existing 120-day selector
at the research cutoff may be stricter. Beyond it, unknown remains unknown.
Known class/split conflicts and income-attribution/negative-denominator guards
remain; no complete corporate-action reconciliation is claimed.
