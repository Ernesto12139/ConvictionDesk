# ConvictionDesk v0.10.0 — Public IVS limited beta

A clean install can explore a real public SEC metadata receipt, fictional
holdings and Thesis, scripted Fast → same-task immutable Deep, cited evidence and
a deterministic Decimal account What-if. Run `python -m market_agent.public_ivs
--serve` and open http://127.0.0.1:8791/.

This uses frozen SEC metadata captured on 2026-10-24, invented prices/accounts,
and scripted responses. It performs no model calls, live data requests or orders.
Opening an original SEC link is an explicit browser navigation outside the demo.
UNDETERMINED is not HOLD; a missing mark is not zero. Thesis comparison remains
UNKNOWN unless a saved before/after comparison actually exists.

The original read-only fictional replay remains `python -m market_agent.serve`
on port8080. Existing SEC source-time/F1/F2 tests, public history auditing and
signed-service witnesses are retained. This release makes no claim about live
model quality, investment accuracy, performance or any person's real portfolio.

See README.md and docs/getting-started.md for Windows/Linux installation,
screenshots, limitations and reproducible verification.
