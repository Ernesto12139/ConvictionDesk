# ConvictionDesk v0.11.0

The existing research Console now exposes workspace identity, local Provider
source-health diagnostics and actual execution Trace receipts. The keyless
sample retains public SEC captures, synthetic accounts, scripted Fast-to-Deep
revisions and deterministic What-if in the same workbench.

An explicit local Owner composition adds qualified holding/SEC/thesis/price
readback and hypothetical adjustments with unknown values preserved. It requires
reviewed source, protected local configuration, backup and admission gates.
Authentication, rights, freshness, consent and budget remain separate states.

No Owner data, credentials or private history are packaged. No live investment
quality, return, Jev cost-saving or cloud operation is claimed. There is no order
execution. See getting-started and candidate scope for setup and data boundaries.

The installed distribution is named `convictiondesk`; Python imports remain
`market_agent`. In an exported installation without Git metadata, code commit
identity is honestly UNKNOWN. Use the packaged source version and release
manifest to identify the source snapshot.
